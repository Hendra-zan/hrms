📥 UNDUH APLIKASI (APK)
📶
WAJIB TERHUBUNG KE WI-FI RUMAH SAKIT
Sebelum mengunduh atau membuka aplikasi, pastikan HP Anda sudah terhubung ke salah satu jaringan Wi-Fi RS berikut:
STAF atau Wifi-Medis
(Aplikasi tidak dapat diakses menggunakan paket data seluler luar).
📌 Langkah-Langkah Instalasi Aplikasi
1
Sambungkan HP ke Wi-Fi RS
  1. Buka Pengaturan / Settings di HP Android Anda.
  2. Pilih Wi-Fi lalu hubungkan ke STAF atau Wifi-Medis.
  3. Pastikan status Wi-Fi sudah Terhubung (Connected).
2
Unduh Berkas Aplikasi (APK)

Ketuk tombol biru di bawah ini untuk mengunduh aplikasi secara langsung:

📥 Unduh File APK (app-release.apk)
3
Izinkan Instalasi dari Sumber Tak Dikenal

Jika muncul peringatan keamanan "Ponsel tidak diizinkan menginstal aplikasi tidak dikenal dari sumber ini":

  1. Ketuk opsi Pengaturan / Settings pada jendela peringatan.
  2. Aktifkan tombol "Izinkan dari sumber ini" (Allow from this source).
  3. Tekan tombol Kembali (Back ◀️) pada HP Anda.
  4. Ketuk Instal / Install.
4
Buka Aplikasi & Berikan Izin Akses
  • Izin Lokasi (GPS): Pilih "Saat Aplikasi Digunakan".
  • Izin Kamera: Pilih "Izinkan / Allow" (digunakan saat selfie presensi).
  • Izin Notifikasi: Pilih "Izinkan / Allow".
5
Login Akun Karyawan

Masukkan NIK / Email Karyawan dan Kata Sandi yang telah diberikan oleh Tim HRD RSU Meloy, lalu tekan tombol Masuk / Login.

❓ Solusi Kendala (Troubleshooting)
❌ Gagal Mengunduh / Halaman Error?
Pastikan Wi-Fi HP Anda terhubung ke STAF atau Wifi-Medis. Coba matikan sementara Data Seluler HP Anda.
📁 File Terunduh Tapi Tidak Ketemu?
Buka aplikasi Pengelola File / File Manager di HP Anda ➔ Masuk ke folder Download ➔ Ketuk file app-release.apk.
🔑 Lupa Kata Sandi / Akun Bermasalah?
Silakan hubungi Sub Bagian Kepegawaian (HRD) atau Tim IT RSU Meloy Sangatta.
